# Fiches matériel (locales)

Ce dossier contient les fiches de vos machines, générées par `scripts/inventory.sh`.
Elles sont **ignorées par git** : elles ne partent jamais sur GitHub.

Dans le dépôt, on désigne les machines par un libellé générique (« poste linux ubuntu », « macbook »),
jamais par leurs caractéristiques exactes ni leur nom d'hôte.
